# Quran Premium v1.6.0 — Phase 7

- versionCode: 7
- applicationId unchanged: `com.qurankareem.app`
- Added verse-by-verse Hifz playback with Alafasy, Husary, Abdul Basit and Sudais options.
- Hifz playback honors ayah repetition and full-range repetition as a finite Media3 playlist (safety limit: 1000 media items per session).
- Added usage statistics: unique pages, reading streak, last-seven-day page activity, audio minutes, Hifz progress and Khatma progress.
- Added three Android home-screen widgets: next prayer, continue reading and daily Wird.
- Download manager now exposes queued/downloading/failed states, byte/percent progress and cancellation.
- Audio downloads preserve `.part` files and resume with HTTP Range where supported by the source server.
- Existing user reading/practice/settings data remains compatible.
